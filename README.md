# ☕ Cafe Search API

Небольшой HTTP-сервис на **Go** для поиска кафе с поддержкой фильтрации результатов и ограничения их количества.

Проект демонстрирует реализацию HTTP-обработчика, работу с query-параметрами и покрытие основных сценариев автоматизированными тестами.

## 🔍 Возможности

Сервис предоставляет endpoint `/cafe`, который позволяет:

- 🏙️ Выбирать город для поиска
- 🔢 Ограничивать количество возвращаемых результатов через `count`
- 🔎 Фильтровать кафе по названию с помощью `search`
- 🔤 Выполнять поиск без учёта регистра
- ⚠️ Обрабатывать некорректные параметры запроса
- 📡 Возвращать соответствующие HTTP-статусы и данные результата

## 📁 Структура проекта

| Файл | Назначение |
|---|---|
| `main.go` | HTTP-обработчик, данные кафе и основная логика сервиса |
| `main_test.go` | Автоматизированные тесты HTTP-обработчика |
| `go.mod` | Описание Go-модуля и зависимостей |
| `go.sum` | Контрольные суммы зависимостей |

## 🧪 Тестирование

Тесты охватывают как стандартные сценарии работы API, так и обработку ошибочных запросов.

### Основные проверки

- `TestCafeWhenOk()` — успешная обработка различных запросов
- `TestCafeNegative()` — проверка некорректных параметров и ошибок
- `TestCafeCount()` — проверка ограничения количества результатов
- `TestCafeSearch()` — проверка фильтрации кафе по поисковому запросу

Для имитации HTTP-запросов без запуска отдельного сервера используется стандартный пакет `net/http/httptest`.

Проверка результатов выполняется с помощью `assert` и `require` из библиотеки **Testify**.

## 🛠️ Используемые технологии

- **Go**
- `net/http`
- `net/http/httptest`
- `testing`
- **Testify**

## 🚀 Запуск

Установить зависимости:

    go mod download

Запустить тесты:

    go test ./...

Для подробного вывода:

    go test -v ./...

Проверить покрытие:

    go test -cover ./...

## 🎯 Цель проекта

Проект предназначен для практики разработки и тестирования HTTP-сервисов на **Go**: работа с query-параметрами, обработка ошибок, формирование HTTP-ответов и написание изолированных тестов для серверной логики.
