# ☕ Cafe Search — Tests

Набор автоматизированных тестов для HTTP-обработчика поиска кафе на Go.

Тесты проверяют обработку параметров запроса, корректность ответов сервера и поведение приложения при некорректных входных данных.

## 🔍 Что проверяется

- ограничение количества результатов с помощью `count`;
- поиск кафе по параметру `search`;
- поиск без учёта регистра;
- корректные HTTP-статусы;
- обработка ошибочных запросов;
- соответствие содержимого ответа ожидаемому результату.

## 📁 Файлы проекта

| Файл | Назначение |
|---|---|
| `main.go` | HTTP-обработчик и данные сервера |
| `main_test.go` | Набор автоматизированных тестов |

## 🧪 Тестовые сценарии

- `TestCafeWhenOk()` — проверяет успешную обработку запросов;
- `TestCafeNegative()` — проверяет ошибки и некорректные параметры;
- `TestCafeCount()` — контролирует количество возвращаемых результатов;
- `TestCafeSearch()` — проверяет работу поиска и фильтрации.

Для создания тестовых HTTP-запросов используется стандартный пакет `httptest`.

Проверки выполняются с помощью `assert` и `require` из библиотеки Testify.

## 🛠️ Используемые технологии

- Go
- `net/http`
- `net/http/httptest`
- `testing`
- Testify
