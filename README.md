☕ Cafe Search Tests

Набор автоматизированных тестов для HTTP-обработчика поиска кафе на Go.

Проект проверяет поведение API при различных комбинациях параметров запроса и помогает контролировать корректность обработки как обычных, так и ошибочных сценариев.

📋 Покрытые сценарии
успешное выполнение запросов к /cafe;
обработка неизвестного города;
проверка обязательных параметров;
ограничение количества результатов через count;
фильтрация результатов по search;
поиск без учёта регистра;
проверка HTTP-кодов ответа;
проверка содержимого полученных данных.

main.go содержит HTTP-обработчик и данные, используемые сервером.

main_test.go содержит набор тестов для проверки различных вариантов работы обработчика.

.github/workflows/test-coverage.yaml используется для автоматического запуска тестов в CI.

🧪 Набор тестов

В проекте предусмотрены отдельные группы проверок:

TestCafeWhenOk — корректные запросы;
TestCafeNegative — обработка ошибочных входных данных;
TestCafeCount — поведение параметра count;
TestCafeSearch — работа поиска и проверка найденных результатов.

Для HTTP-запросов используются httptest, а для утверждений — assert и require из Testify.

🚀 Запуск

Установить зависимости:

go mod download

Запустить тесты:

go test ./...

Запустить тесты с подробным выводом:

go test -v ./...

Проверить покрытие:

go test -cover ./...
🎯 Цель проекта
